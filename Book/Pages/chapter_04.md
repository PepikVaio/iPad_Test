# Pokročilý uživatel

Pokročilé možnosti Bindery umožňují upravit vzhled výsledné knihy.

Tato část je určena uživatelům, kteří chtějí mít větší kontrolu nad typografií, písmem a vzhledem jednotlivých prvků.

## Písma

Bindery umožňuje používat vlastní písma.

Fonty mohou být součástí projektu knihy a následně použity při generování výsledného dokumentu.

Použití vlastního písma umožňuje například:

- změnit vzhled běžného textu,
- použít jiné písmo pro nadpisy,
- používat vlastní typografii,
- vytvořit jednotný vzhled celé knihy.

Při používání vlastních fontů je potřeba zachovat jejich správné umístění a správné názvy souborů.

Podporované typy fontů závisí na konkrétním výstupním formátu a způsobu jejich použití.

## CSS

Vzhled knihy lze upravovat pomocí CSS.

CSS určuje například:

- velikost textu,
- typ písma,
- řádkování,
- zarovnání,
- mezery,
- vzhled nadpisů,
- vzhled odstavců,
- vzhled obrázků,
- další vizuální vlastnosti dokumentu.

Díky CSS není nutné měnit samotný text knihy pokaždé, když chcete upravit její vzhled.

Text zůstává v Markdown souborech a vzhled je možné upravovat samostatně.

## Proč používat vlastní CSS

Výchozí vzhled Bindery je vhodný pro vytvoření knihy bez nutnosti cokoli nastavovat.

Vlastní CSS je užitečné ve chvíli, kdy chcete vytvořit vlastní vzhled.

Například můžete vytvořit:

- technickou dokumentaci,
- román,
- učebnici,
- katalog,
- pracovní sešit,
- vlastní typografický styl.

Čím více CSS upravíte, tím více můžete výslednou podobu knihy přizpůsobit svému projektu.
